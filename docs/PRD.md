# 사이트 설계도(PRD) — 영빈식당

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
무등산 아래에서 다양한 반찬이 올라오는 보리밥 한정식 상차림을 내는 식당.

## 2. 손님
- 누가: 무등산 등산객, 가족 손님 (산악회·가족 모임 같은 단체 포함)
- 어디서 알고 오나: 입소문

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 위치·주차 — 등산로에서 어떻게 오는지, 차를 댈 수 있는지
2. (미정)
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 상차림 사진 (실제 상 사진)
- 후기: 네이버 등에 손님이 남긴 실제 후기 (사용자가 고른 것만 그대로 옮긴다. 지어내지 않는다)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 예약·단체 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 상차림 사진 + 버튼
2. 상차림 — 반찬이 가득 올라온 보리밥 한정식 사진, 가격(2인 기준 제공, 1인 12,000원)
3. 오시는 길 — 주소, 영업시간, 전화, 지도 링크, 주차 안내(미정)
4. 후기 자리 — 네이버 등 실제 후기 (없으면 비워 둠)
5. 문의 폼 — 예약·단체 문의

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 문의 내용 (칸 안내 문구 예: "방문 날짜, 인원, 하고 싶은 말을 적어 주세요")
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가게 이름: 영빈식당
- 가격: 2인 기준 제공, 1인: 12,000원
- 시간: 11시 ~ 18시
- 위치: 광주광역시 동구 지호로 137-3
- 연락 방법: 062-227-5011
- 쉬는 날: (미정)
- 주차: (미정)
- 단체 최대 인원: (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 온라인 결제, 예약금
- 날짜를 골라 확정하는 예약 시스템 (이번에는 문의 폼으로 받고 전화로 확정)
- 알림 메일·문자
- 블로그·공지사항

## 10. 첫 화면 한 문장 후보
1. 무등산 산행 끝, 반찬 가득한 보리밥 한 상
2. 등산 후 가족과 함께, 영빈식당 보리밥 한정식
3. 다양한 반찬이 차려지는 보리밥 상차림, 단체 예약도 받아요

## 11. 다음에 할 것
- 주차·쉬는 날·단체 최대 인원 정보 채우기
- 실제 후기 골라서 넣기
- 가게·내부 사진 추가
- 위 9번 항목 중 필요한 것

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
